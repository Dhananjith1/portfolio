# Project-management case studies

These are documentation-only project-management simulations prepared for portfolio review. They focus on scope definition, delivery planning, stakeholder coordination, backlog or workflow management, risks, and measurable acceptance criteria.

They are **not** software implementation repositories. Where a project includes a product or performance concept, the document distinguishes planned targets and modelled outcomes from tested results.

## How to read these documents

Each case study states its simulation context, planning focus, tools, deliverables, success criteria, and limitations. References to tools such as Jira, ClickUp, Notion, Excel, or Power BI describe the planning workflow used or modelled; they do not mean that a production service was deployed.
