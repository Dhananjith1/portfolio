# DIMO AgriCare — Field-Service Dispatch

<small>Classification: Project-management simulation · Tool: Jira Kanban · Scenario target: under 4 hours</small>

## Overview

DIMO AgriCare is a simulated field-service dispatch scenario for agricultural machinery support. The planning exercise considers how a service team might coordinate incoming requests, technician assignment, work progress, and updates to the customer.

The example uses a CLAAS harvester service case to practise setting a service-response target. It does not imply a project, partnership, endorsement, or live service relationship with DIMO or CLAAS.

## Objective

Practise making field-service work visible, limiting work in progress, and defining a clear target for dispatch coordination.

## Workflow planning

- Modelled a five-stage Kanban workflow in Jira.
- Applied work-in-progress (WIP) limits to make overloaded stages visible.
- Considered intake, prioritisation, assignment, work progress, and completion as areas the team would need to coordinate. The exact stage names and operating rules would be confirmed with real stakeholders in an actual project.
- Used a **less-than-four-hour** service target for the simulated CLAAS harvester case.

## Project-management work

The simulation focuses on workflow design, WIP control, ownership, priority rules, service-target visibility, bottleneck identification, and escalation planning.

## Success criteria for the simulation

- Every work item has a clear owner and status.
- WIP limits make overloaded stages visible.
- Urgent service cases can be identified and escalated.
- The under-four-hour target is tracked as a target, with any missed target visible for review.

## Limitations

The under-four-hour value is a planning target, not a measured response or repair time. No actual field-service dispatch, technician visit, machine repair, or DIMO/CLAAS operational data is represented.
