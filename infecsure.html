InfecSure — AI-Assisted Infection Monitoring

Project Manager (Lead) · Roadmap Planning & Coordination

An academic software prototype exploring how infection-risk indicators could be organized for monitoring and review in an isolation-ward context.

Python / FastAPIReactFirebaseRandom Forest

Project overview

InfecSure was scoped as an AI-assisted monitoring prototype for an academic campus project. The proposed web application structure included a FastAPI service, a React interface, and Firebase as part of the data layer.

My project role

My contribution focused mainly on project management: planning the development roadmap, organizing the delivery scope, and coordinating the work around the planned application.

  • Roadmap and milestone planning
  • Project scope and coordination
  • Communication and delivery tracking

Prototype configuration

The academic prototype's Random Forest model configuration used these selected parameters:

  • 200 estimators
  • Maximum depth: 10
  • Minimum samples split: 5
  • Minimum samples leaf: 2
  • Random state: 42

Risk-alert thresholds

The prototype's configurable Z-score thresholds were set to:

  • Warning threshold: 2.0
  • Critical threshold: 3.0

These values describe the project configuration, not a clinically validated standard.

Important limitation: InfecSure is an academic prototype. Its model configuration and alert thresholds have not been presented as clinically validated or suitable for diagnosis, treatment, or real-world clinical decisions.
